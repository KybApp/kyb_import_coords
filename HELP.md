# Импорт данных — подробная справка

Полное описание всех возможностей плагина. Если вы
запускаете его впервые — начните с раздела «Быстрый старт».

---

## 1. Быстрый старт

1. Откройте плагин: **Плагины → Импорт данных**.
2. Загрузите данные одним из трёх способов:
   - **Файл** → нажмите «...» и выберите файл;
   - **Из буфера** → скопируйте текст и нажмите кнопку;
   - **Перетащите** файл прямо в окно плагина.
3. Посмотрите на таблицу и карту. Если что-то не так —
   поправьте настройки.
4. Введите имя слоя (обязательно).
5. Нажмите **«Импортировать»**.

Пока не нажата кнопка «Импортировать», в проект QGIS ничего
не добавляется. Это сделано специально: сначала проверяем,
потом импортируем.

---

## 2. Окно плагина

Слева — предпросмотр: таблица данных сверху, карта снизу.
Справа — блоки настроек:

- **Источник данных** — файл и исходная система координат.
- **Структура** — параметры разбора.
- **Геометрия** — тип объектов, стиль, вспомогательные слои.
- **Результат** — имя слоя и сохранение в GeoPackage.

Внизу — кнопки **Очистить данные**, **Импортировать**, **Отмена**.

---

## 3. Источник данных

### Поле «Файл»

Путь к загруженному файлу. Поддерживается перетаскивание (drag&drop).

### Кнопка «...»

Стандартный диалог выбора. Фильтр предлагает:

- всё поддерживаемое;
- только текстовые;
- только Excel;
- только пространственные;
- любые файлы.

### Кнопка «Из буфера»

Берёт текст из системного буфера обмена. Удобно, если данные
скопированы из Excel, браузера или другого документа.

### Исходная СК

Система координат исходных данных. Выбирается из стандартного
диалога QGIS. Поддерживаются:

- стандартные EPSG;
- пользовательские СК, добавленные через
  **Настройки → Свои СК** (они показываются как `USER:xxxxx`).

**Проверка СК.** При нажатии «Импортировать» плагин проверяет:

1. СК распознаётся QGIS. Если нет — импорт блокируется,
   блок СК подсвечивается красным.
2. Единицы данных совпадают с типом СК: метры — проекционная,
   градусы — географическая. Если нет — предупреждение с
   вопросом «продолжить?».

При несовпадении единиц в блоке «Источник данных» появляется
жёлтая плашка — она видна сразу после загрузки данных.

## 4. Структура

### Формат

Определяется автоматически:

- **Десятичные** — `55.7244	36.3638`;
- **ГМС в одной колонке** — `55°43'28.05"`;
- **ГМС в трёх колонках** — `55	43	28.05	36	21	49.94`.

### Заголовки

Определяются по содержимому: если в первой строке чисел
заметно меньше, чем в данных — считаем её заголовком.

### Нач./Кон. строка

Позволяют отрезать шапку или хвост файла. `Кон. строка = 0`
означает «до конца».

### Кодировка

`UTF-8`, `CP1251`, `UTF-16`. По умолчанию UTF-8.
Применяется только к текстовым файлам.

### Разделитель

`авто` (по умолчанию), `таб`, `запятая`, `точка с запятой`,
`пробел`. Авторежим выбирает самый стабильный разделитель
по первым 15 строкам.

### Порядок / Оси

Показывается один из двух переключателей:

- **Порядок: Широта, Долгота / Долгота, Широта** — для градусов;
- **Оси: Север, Восток / Восток, Север** — для метров.

По умолчанию — Север, Восток для метров и Широта, Долгота
для градусов. Это соответствует геодезическому порядку осей
в МСК, ГСК-2011 и СК-42.

### Поля координат

Подписи полей меняются автоматически:

- для метров — **Север:** / **Восток:**
  (или наоборот, если выбрано «Восток, Север»);
- для градусов — **Широта:** / **Долгота:**
  (или наоборот, если выбрано «Долгота, Широта»).

Количество полей зависит от формата:

- Десятичные — 2;
- ГМС в одной колонке — 2;
- ГМС в трёх колонках — 6.

## 5. Геометрия

### Тип геометрии

- **Точка** — каждая строка = отдельная точка.
- **Линия** — один блок = одна линия.
- **Полигон** — блок делится на подполигоны по повтору
  первой точки.
- **Многоконтурный полигон** — как полигон, но все контуры
  хранятся в одном объекте.

**Пустая строка** между блоками — всегда граница нового объекта.

Для пространственных файлов тип определяется автоматически
и не может быть изменён — данные уже такие.

### Стиль полигона

- **Контур** — только граница.
- **Заливка** — только заливка.
- **Контур + заливка** — и то, и другое.

Цвета настраиваются кнопкой **⚙**.

### Точки по углам

Создаёт отдельный слой с вершинами линий и полигонов.
Полезно для проверки координат углов.

### Нумерация точек и углов

Включает подписи с номерами:

- для точек — номер каждого объекта;
- для линий и полигонов — номер каждой вершины.

Если включена нумерация без «Точек по углам», для линий
и полигонов слой вершин всё равно создаётся —
подписи ставятся на него.

### Кнопка «⚙»

Открывает диалог настроек отображения. Подробнее — раздел 8.

---

## 6. Результат

### Имя слоя

Обязательное поле. Если пусто — при нажатии «Импортировать»
появится жёлтая плашка под полем и красная рамка вокруг него.
Как только начинаете вводить — подсветка уходит.

Для пространственного файла на выходе может получиться
несколько слоёв:

- `<имя> — точки`;
- `<имя> — линии`;
- `<имя> — полигоны`.

Каждый тип геометрии — отдельный слой.

### Сохранить в файл (GeoPackage)

Если включено — результат пишется в `.gpkg`, и в проект
добавляется загруженный из файла слой, а не временный.

Если файл уже существует:

- слои с такими именами перезаписываются;
- остальные слои в файле остаются.

### Слой вершин

Если включены «Точки по углам» или «Нумерация», создаётся
второй слой `<имя> — вершины`. Поля: `num`, `vertex`.

## 7. Таблица предпросмотра

Одна строка — одна точка или один объект.

### Для текстовых данных

Показываются все исходные колонки как есть. Между блоками —
серая строка-разделитель.

### Для пространственных файлов

Показываются вершины объектов:

| № | №верш | Тип | Широта | Долгота | Площадь, м² | Площадь, га | Периметр/длина, м |
|---|---|---|---|---|---|---|---|
| 1 | 1 | Линия | 55.67636570 | 36.38513157 |  |  | 1456.26 |
| 1 | 2 | Линия | 55.67640800 | 36.38520000 |  |  |  |
| 2 | 1 | Линия | 55.67068883 | 36.39346872 |  |  | 190.33 |

Площадь и длина заполнены **только в первой строке объекта**.
Остальные вершины — с координатами, без дублирования свойств.

### Контекстное меню (правый клик)

- **Копировать** — выделенные ячейки в буфер как TSV
  (вставляется в Excel);
- **Добавить строку** — пустая строка после текущей;
- **Удалить строку** — убрать текущую строку.

Правки строк применяются к данным и сразу отражаются
на карте. Точки исчезают / появляются мгновенно.

---

## 8. Настройки отображения (⚙)

Диалог настраивает цвета и размеры элементов на карте.
Изменения применяются сразу после нажатия «OK».

### Точки

- Цвет
- Размер в пикселях

### Линии

- Цвет
- Толщина в пикселях

### Полигоны

- Цвет контура
- Толщина контура
- Цвет заливки (с альфа-каналом — можно полупрозрачный)

### Подписи

- Цвет номеров углов
- Размер номеров
- Цвет площадей
- Размер площадей

### Кнопка «Сбросить»

Возвращает все значения к дефолтным:

- точки — синие, 6 px;
- линии — зелёные, 2 px;
- контур полигона — красный, 2 px;
- заливка — розовая полупрозрачная;
- номера — красные, 10 pt;
- площади — синие, 10 pt.

Настройки сохраняются в QgsSettings и восстанавливаются
при следующем запуске QGIS.

---

## 9. Карта предпросмотра

### Что видно

- Геометрия объектов — цветом по текущим настройкам.
- Подписи номеров углов (если включено).
- Подписи площадей (для полигонов) — вид `S₁=21237.18 м²`.
- Общая площадь в левом верхнем углу (для полигонов).
- Масштабная линейка в левом нижнем углу.

### Масштабная линейка

- Показывает метры или километры.
- Для проекционных СК — на основе масштаба канвы.
- Для географических СК — по Web Mercator
  (как на веб-картах).

### Общая площадь

Считается по всем полигонам в превью. Обновляется при каждой
перерисовке — например, когда удаляешь строку в таблице.

---

## 10. Расчёт площадей и длин

### Единицы

- Площадь — м² и га (в атрибутах), м² (в подписях).
- Длина — метры.

### Как считаются

**Для проекционных СК** (МСК, ГСК-2011, СК-42, UTM):

- стандартные формулы QGIS.

**Для географических СК** (EPSG:4326, WGS84):

- через Web Mercator. Считаем метры на градус долготы
  на широте центроида объекта: `R·cos(φ)·π/180`,
  где `R = 6378137`.

Приближение верно для объектов в пределах нескольких
километров. Для крупных объектов (> 10 км) площадь может
слегка отличаться от расчёта в правильной проекции.

### Точность

- Площадь в м² — 2 знака.
- Площадь в га — 4 знака.
- Периметр и длина в м — 2 знака.

## 11. Excel и пространственные файлы

### Excel (`.xls`, `.xlsx`, `.ods`)

Читается через GDAL/OGR — встроенный в QGIS.
Внешние библиотеки не требуются.

- Берётся первый непустой лист.
- Первая строка трактуется как заголовки.
- Ограничение: если в файле **нет заголовков**,
  первая строка данных потеряется. Сохраните файл
  в `.csv` и загрузите как текст.

### Пространственные файлы

Читаются через GDAL/OGR.

- **Shapefile** — путь к `.shp`, остальные части
  (`.dbf`, `.shx`, `.prj`) подтягиваются автоматически.
- **GeoJSON** — расширения `.geojson` или `.json`.
- **KML** — только WGS84 по стандарту.
- **GeoPackage** — первый лист/слой.

**Атрибуты переносятся** из исходного файла. Если в шейпе были
поля `name`, `type`, `лесничество` — они попадут в итоговый
слой вместе с нашими `num`, `area_m2` и т.д.

**Смешанные типы.** Если в одном KML есть и точки, и линии,
и полигоны — плагин разбивает их на три слоя на выходе.
В превью показываются все объекты с цветами по типу.

## 12. Сохранение и загрузка настроек

Что запоминается между запусками:

- разделитель и кодировка;
- исходная СК;
- тип геометрии;
- стиль полигона;
- порядок осей / порядок ШД;
- галочки «Точки по углам» и «Нумерация»;
- путь сохранения в GeoPackage и её галочка;
- все настройки отображения (цвета и размеры).

Хранится в QgsSettings под префиксом `KYB_import_coords/`.

**Сбросить всё.** Плагины → Управление плагинами → вкладка
«Настройки» → «Открыть папку настроек» → ищите файл
`QGIS3.ini`, найдите блок `[KYB_import_coords]` и удалите его.

---

## 13. Кнопка «Очистить данные»

Полностью сбрасывает текущее состояние:

- поле файла;
- данные и таблицу;
- карту и все подписи;
- признаки spatial-входа.

Поля «Формат», «Разделитель», «Координаты» возвращаются
к видимому состоянию. Настройки (разделитель, СК, цвета)
**не сбрасываются** — они остаются как были.

Если загружаешь новый источник, очистка происходит
**автоматически** перед загрузкой — вручную жать не нужно.

## 14. Частые вопросы

**Плагин не появляется в меню.**
Проверьте путь: внутри папки `KYB_import_coords` должны
лежать файлы `__init__.py`, `plugin.py` и т.д. Если в папке
ещё одна вложенная папка `KYB_import_coords` — переложите
файлы на уровень выше. Перезапустите QGIS.

**Файл не загружается — «Не похоже на координаты».**
Причины: не тот разделитель, не та кодировка, в данных
текст вместо чисел. Проверьте предпросмотр первых строк —
там видно, как плагин разобрал файл.

**«Не удалось прочитать Excel».**
Файл защищён паролем или повреждён. Откройте в Excel
и сохраните как `.csv`.

**Ошибка «Неверная система координат».**
Выбрана СК, которой нет в QGIS. Откройте список, выберите
стандартную, или добавьте свою через
**Настройки → Свои СК**.

**Предупреждение «Данные не согласованы с СК».**
Данные в метрах, а СК географическая (или наоборот).
Скорее всего, выбрана не та СК — проверьте.

**Площади выглядят странно (очень большие или маленькие).**
Скорее всего, СК в градусах, а данные — в метрах.
Или наоборот. Плагин предупредит об этом при импорте.

**Подписи площадей перекрывают контур.**
Пока не исправлено. Подпись ставится в центроид контура.
Для сложных «бутылочных» полигонов может лечь на грань.

---

## 15. Что появится в следующих версиях

- Точки внутри контура (не центроид) для подписи площади.
- Дополнительные форматы на входе.
- Обрезка по экстенту / по полигону.

Список формируется по замечаниям пользователей.
Присылайте — что неудобно, что ломается, каких данных не хватает.
