# KYB_import_coords

Плагин QGIS для импорта и **проверки** пространственных данных.
Превращает координаты из текста, таблиц и готовых ГИС-файлов
в векторные слои и показывает характеристики объектов до импорта.

## Что делает

Одна операция: взял данные — посмотрел превью — импортировал в QGIS.
Прежде чем попасть в проект, объекты показываются в отдельном окне:
таблица + карта. Пользователь сравнивает координаты, площади,
периметры, конфигурацию — со своими эталонами. Только потом — импорт.

Плагин автоматически считает метрики объектов (площадь, периметр,
длину) и умеет отображать координаты как в десятичных градусах,
так и в формате ГГ°ММ'СС.ссс".

## Требования

- **QGIS 3.28** или новее. Проверено на 3.44 LTR и 4.2.
- Никаких внешних библиотек устанавливать не нужно.
  Чтение Excel и пространственных файлов идёт через GDAL/OGR,
  встроенный в QGIS.

## Установка

1. Закрыть QGIS.
2. Распаковать архив. Внутри должна лежать папка `KYB_import_coords`,
   а в ней — файлы `__init__.py`, `plugin.py`, `dialog.py`,
   `metadata.txt`, `icon.png`, `README.md`, `HELP.md`, `LICENSE`.
3. Положить папку `KYB_import_coords` в:
   - **Windows:**
     `C:\Users\<имя>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
   - **Linux:**
     `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
4. Запустить QGIS.
5. Открыть **Плагины → Управление плагинами**, найти «Импорт данных»,
   поставить галочку.

После этого в меню появится **Плагины → Импорт данных**,
а на панели инструментов **KYB_TOOLS** — кнопка запуска.

## Кратко о работе

1. Открыть плагин.
2. Загрузить данные одним из способов:
   - нажать **«...»** и выбрать файл;
   - нажать **«Из буфера»** — данные уже скопированы;
   - перетащить файл прямо в окно.
3. Проверить таблицу и карту.
4. Указать имя слоя.
5. Нажать **«Импортировать»**.

## Что принимает на вход

### Текстовые файлы (`.csv`, `.txt`, `.tab`)

Таблица с координатами. Одна строка — одна точка.
Поддерживаются три формата координат (определяются автоматически):

| Формат | Пример |
|---|---|
| Десятичные градусы | `55.72445833	36.36387222` |
| ГМС в одной колонке | `55°43'28.05"	36°21'49.94"` |
| ГМС в трёх колонках | `55	43	28.05	36	21	49.94` |
| Прямоугольные (метры) | `465457.47	1305443.78` |

Разделитель — таб, запятая, точка с запятой, пробел.
Определяется автоматически, можно выбрать вручную.
Если выбранный разделитель не подходит, плагин предложит
переключиться на подходящий.

### Таблицы Excel (`.xls`, `.xlsx`, `.ods`)

Первый непустой лист файла. Первая строка трактуется как заголовки.
Читается встроенными средствами QGIS (GDAL), никаких дополнений
устанавливать не нужно.

### Пространственные файлы

- **Shapefile** (`.shp`) — с соседними `.dbf`, `.shx`, `.prj`;
- **GeoJSON** (`.geojson`, `.json`);
- **KML** (`.kml`);
- **GeoPackage** (`.gpkg`).

Геометрия берётся из файла, СК — из файла. Исходные атрибуты
переносятся в итоговый слой. Если в файле смешаны разные типы
(например, точки и линии) — на выходе создаётся **несколько слоёв**
по типам геометрии.

## Что можно настроить

- Разделитель, кодировка, диапазон строк.
- Порядок координат: Широта/Долгота или Север/Восток.
- Исходная СК — из списка QGIS или своя.
- Геометрия: точка, линия, полигон, мультиполигон.
- Стиль полигона: контур, заливка, контур + заливка.
- Точки по углам и нумерация вершин (режимы: авто-по-объектам,
  авто-сквозная, из колонки).
- Имя слоя и сохранение в GeoPackage.

### Кнопки «⚙» (настройки)

В плагине два диалога настроек:

- **В блоке «Структура»** — настройки формата и точности координат.
  Можно выбрать десятичный формат или ГГММСС, и задать количество
  знаков после запятой для градусов, секунд и метров.
- **В блоке «Геометрия»** — настройки отображения. Цвета и размеры
  точек, линий, контуров и заливок, а также подписей номеров и площадей.

## Что попадает в атрибуты слоя

Для полигонов:
- `num` — номер объекта;
- `z` — высота (если есть);
- `area_m2` — площадь в м²;
- `area_ha` — площадь в гектарах;
- `perimeter_m` — периметр в метрах.

Для линий:
- `num`, `z`, `length_m` (длина в метрах).

Для точек:
- `num`, `z`.

Для пространственных файлов — все исходные атрибуты + наши расчётные поля.

**Слой вершин** (если включен) получает:
- `num` — номер объекта;
- `vertex` — номер вершины. Тип поля — **строка**, чтобы поддерживать
  нумерацию из исходных данных (например, «А-12», «Угол 15»).

## Как считаются площади и длины

- **В метрах:** стандартные формулы QGIS.
- **В градусах:** через Web Mercator. Для площади учитывается широта
  центроида объекта, для длины — широта середины каждого сегмента.
  Это даёт корректные метры для объектов до нескольких километров.

## Ограничения превью-таблицы

- Для каждого объекта показывается не более 80 вершин. Если вершин
  больше, в таблице появляется строка `... скрыто вершин: N ...`.
  Полный набор вершин будет виден в атрибутах слоя после импорта.
- Округление координат в таблице — **только визуальное**. В слой
  уходят полные исходные значения.

## Где хранятся настройки

Плагин запоминает разделитель, СК, геометрию, стиль, цвета,
формат координат и путь сохранения. При следующем запуске
всё встанет как было.
