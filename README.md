# KYB_import_coords

Плагин QGIS для импорта и **проверки** пространственных данных.
Превращает координаты из текста, таблиц и готовых ГИС-файлов
в векторные слои и показывает характеристики объектов до импорта.

## Что делает

Одна операция: взял данные — посмотрел превью — импортировал в QGIS.
Прежде чем попасть в проект, объекты показываются в отдельном окне:
таблица + карта. Пользователь сравнивает координаты, площади,
периметры, конфигурацию — со своими эталонами. Только потом — импорт.

## Требования

- **QGIS 3.28** или новее. Проверено на 3.44 LTR и 4.2.
- Никаких внешних библиотек устанавливать не нужно.
  Чтение Excel и пространственных файлов идёт через GDAL/OGR,
  встроенный в QGIS.

## Установка

1. Закрыть QGIS.
2. Распаковать архив. Внутри должна лежать папка `KYB_import_coords`,
   а в ней — файлы `__init__.py`, `plugin.py`, `dialog.py`,
   `metadata.txt`, `icon.png`, `README.md`, `HELP.md`.
3. Положить папку `KYB_import_coords` в:
   - **Windows:**
     `C:\Users\<имя>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
   - **Linux:**
     `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
4. Запустить QGIS.
5. Открыть **Плагины → Управление плагинами**, найти «Импорт данных»,
   поставить галочку.

После этого в меню появится **Плагины → Импорт данных**,
а на панели инструментов — кнопка.

## Кратко о работе

1. Открыть плагин.
2. Загрузить данные одним из способов:
   - нажать **«...»** и выбрать файл;
   - нажать **«Из буфера»** — данные уже скопированы;
   - перетащить файл прямо в окно.
3. Проверить таблицу и карту.
4. Указать имя слоя.
5. Нажать **«Импортировать»**.

## Что принимает на вход

### Текстовые файлы (`.csv`, `.txt`, `.tab`)

Таблица с координатами. Одна строка — одна точка.
Поддерживаются три формата координат (определяются автоматически):

| Формат | Пример |
|---|---|
| Десятичные градусы | `55.72445833	36.36387222` |
| ГМС в одной колонке | `55°43'28.05"	36°21'49.94"` |
| ГМС в трёх колонках | `55	43	28.05	36	21	49.94` |
| Прямоугольные (метры) | `465457.47	1305443.78` |

Разделитель — таб, запятая, точка с запятой, пробел.
Определяется автоматически, можно выбрать вручную.

### Таблицы Excel (`.xls`, `.xlsx`, `.ods`)

Первый непустой лист файла. Первая строка трактуется как заголовки.

### Пространственные файлы

- **Shapefile** (`.shp`) — с соседними `.dbf`, `.shx`, `.prj`;
- **GeoJSON** (`.geojson`, `.json`);
- **KML** (`.kml`);
- **GeoPackage** (`.gpkg`).

Геометрия берётся из файла, СК — из файла. Атрибуты
переносятся в итоговый слой.

## Что можно настроить

- Разделитель, кодировка, диапазон строк.
- Порядок координат: Широта/Долгота или Север/Восток.
- Исходная СК — из списка QGIS или своя.
- Геометрия: точка, линия, полигон, мультиполигон.
- Стиль полигона: контур, заливка, контур + заливка.
- Точки по углам и нумерация углов (отдельный слой и подписи).
- Имя слоя и сохранение в GeoPackage.
- Цвета и размеры элементов — кнопка **⚙** рядом со «Стиль».

## Что попадает в атрибуты слоя

Для полигонов:
- `num` — номер объекта;
- `area_m2` — площадь в м²;
- `area_ha` — площадь в гектарах;
- `perimeter_m` — периметр в метрах.

Для линий:
- `num`, `length_m`.

Для точек:
- `num`.

Для пространственных файлов — все исходные атрибуты + наши
расчётные поля.

## Где хранятся настройки

Плагин запоминает разделитель, СК, геометрию, стиль, цвета
и путь сохранения. При следующем запуске всё встанет как было.
